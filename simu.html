RAG Simulator

Learn Retrieval-Augmented Generation by following the data.

From document → retrieval → grounded answer

This interactive simulator shows what happens inside a simple RAG system. Move through each stage, run the retrieval, and watch the user's question become context for the LLM.

Learning path
Core mental model RAG is not the LLM itself. RAG is the process of finding useful external information and giving that information to the LLM before generation.
